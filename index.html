❓ ຊອກຫາ / ເຊື່ອມຕໍ່ເຄື່ອງພິມບໍ່ໄດ້?
ລະບົບພິມມີ 2 ແບບ — ເລືອກໂໝດຢູ່ດ້ານເທິງໃຫ້ຖືກກັບອຸປະກອນທີ່ໃຊ້:
  1. 💻 ພິມຜ່ານຄອມພິວເຕີ (USB/Bluetooth): ໃຊ້ໄດ້ທັງເຄື່ອງພິມທີ່ຕໍ່ຜ່ານສາຍ USB ແລະ ເຄື່ອງພິມ Bluetooth. ເລືອກໂໝດ 💻 ຄອມພິວເຕີ → ກົດ 👁 Preview → ກົດ 🖨 ພິມຜ່ານຄອມພິວເຕີ → ຖ້າມີ USB ລະບົບຈະໃຫ້ເລືອກ COM port ກ່ອນ (ໃຊ້ໄດ້ດີສຸດ, ໂຄ້ດແບບເກົ່າ ສົ່ງຄັ້ງດຽວ); ຖ້າຍົກເລີກ ຫຼືບໍ່ມີ USB ລະບົບຈະເປີດປ໋ອບອັບໃຫ້ເລືອກເຄື່ອງພິມ Bluetooth ແທນ. ໃຊ້ໄດ້ກັບ Google Chrome ຫຼື Microsoft Edge ເທົ່ານັ້ນ.
  2. 📱 ພິມຜ່ານມືຖື: ກົດ 👁 Preview → ກົດ 🖨 ພິມເລີຍ (ຮູບ PNG) — ລະບົບຈະສ້າງໃບບິນເປັນຮູບພາບກ່ອນ ບໍ່ໄດ້ສົ່ງໂຄ້ດຕົວອັກສອນຊື່ໆໄປເຄື່ອງພິມ (ນີ້ຄືສາເຫດທີ່ພິມແລ້ວເປັນຕົວອັກສອນແປກໆ/ພາສາຕ່າງດ້າວ). ຖ້າມືຖືຂຶ້ນໜ້າຈໍ "ແຊຣ໌" (Share) ໃຫ້ເລືອກແອັບພິມ (Thermer, RawBT, Loyverse ຫຼືແອັບຂອງຍີ່ຫໍ້ເຄື່ອງພິມ) ແລ້ວກົດພິມ — ຮູບພາບຈະພິມອອກຖືກຕ້ອງສະເໝີ.
  3. ຖ້າບໍ່ຂຶ້ນໜ້າຈໍ Share: ລະບົບຈະເປີດຮູບບິນຢູ່ແທັບໃໝ່ ໃຫ້ກົດປຸ່ມ 🖨 ພິມ / Print ໃນໜ້ານັ້ນ ຫຼືກົດ 💾 ບັນທຶກຮູບ ເພື່ອເກັບຮູບໄວ້ພິມພາຍຫຼັງ.
  4. ປຸ່ມ ⚡ BT ກົງ ໃນໂໝດມືຖື ແມ່ນສົ່ງໂຄ້ດພິມກົງໄປເຄື່ອງພິມຜ່ານ Bluetooth — ໃຊ້ໄດ້ຖ້າເຄື່ອງພິມຂອງທ່ານຮອງຮັບ, ແຕ່ຖ້າພິມແລ້ວແປກໆ ໃຫ້ໃຊ້ວິທີຮູບ PNG ແທນ.
